# Metrage | Умный калькулятор для ремонта

**Metrage** — это веб-сервис, разработанный в рамках университетского проекта по дисциплине «Проектная деятельность». 

Приложение помогает людям без профессионального опыта точно рассчитать необходимое количество материалов для ремонта, исключить ошибки в вычислениях и сэкономить бюджет. Сервис переводит сложные формулы в понятный пошаговый сценарий.

## ✨ Основные возможности

*   **4 калькулятора:** расчет краски, керамической плитки, обоев и напольных покрытий.
*   **Умный расчет:** учет площади проемов (двери, окна), количества слоев краски, технологического запаса на подрезку и стыковку рисунка.
*   **Личный кабинет:** регистрация и авторизация пользователей с использованием JWT-токенов
*   **История расчетов:** сохранение всех вычислений в базу данных для доступа с любого устройства.
*   **Интеграция с маркетплейсами:** прямые ссылки для поиска и покупки рассчитанных материалов на Wildberries, Ozon и Яндекс Маркет
