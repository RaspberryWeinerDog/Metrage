# Metrage
Учебный проект (MVP): веб-сервис Metrage для расчета материалов при ремонте.Рассчитывает необходимое количество краски, плитки, обоев и напольных покрытий. Реализованы личный кабинет, база данных для хранения смет и интеграция с WB, Ozon и Яндекс Маркет. Технологии: читый JS, Node.js, SQLite.
