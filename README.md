# Metrage
Учебный проект для университета: веб-сервис Metrage для расчета материалов при ремонте. Рассчитывает необходимое количество краски, плитки, обоев и напольных покрытий. Реализованы личный кабинет, база данных для хранения расчетов и интеграция с WB, Ozon и Яндекс Маркет. Технологии: читый JS, Node.js, SQLite.
